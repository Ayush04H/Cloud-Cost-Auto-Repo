  <files>backend/app/solver/cpsat_solver.py</files>

  <action>
Create `backend/app/solver/cpsat_solver.py` implementing `solve_cluster_packing(snapshot: ClusterSnapshot, policy: ClusterPolicy, max_seconds: float = 3.0, num_workers: int = 2) -> PackingResult`:
1. **Variable Pre-Pruning:** Create `x[(p_idx, n_idx)] = model.NewBoolVar(...)` ONLY when:
   - `node.az in policy.allowed_zones`
   - `pod.spot_tolerant or not node.is_spot`
   - `pod.arch == node.arch`
   Fail fast with a clear `ValueError` if any pod has 0 valid candidate nodes.
2. **Hard Constraints:**
   - `model.AddExactlyOne(valid_vars_for_pod)` for every pod.
   - `node_used[n_idx]` linked via `model.AddMaxEquality(node_used[n_idx], assigned_vars)` (or `0` if no candidate pods).
   - CPU & Memory capacity: `sum(pod.cpu_milli * x[p, n]) <= node.cpu_cap_milli` and `sum(pod.mem_mb * x[p, n]) <= node.mem_cap_mb`.
   - **$O(N)$ Grouped Anti-Affinity:** Group pods on each node by `replica_group_id` (and for services in `policy.strict_anti_affinity_services`, group by `service_name` if `replica_group_id` is None) and add `model.Add(sum(x[p, n] for p in group) <= 1)`.
   - **Spot Allocation Ratio:** `sum(x[p, n] for (p, n) in x if nodes[n].is_spot) <= int(len(pods) * policy.spot_allocation_ratio)`.
3. **Soft Objective (Integer-Only):**
   - Primary: `node_used[n] * node.hourly_price_micros` (or monthly equivalent).
   - Cross-AZ spread penalty: small integer weight per extra AZ used by a multi-replica service.
   - Graviton preference: if `policy.require_graviton_arm64`, add a small bonus/discount weight for `ARM64` nodes.
4. **Bounded Solve & Cleanup:** Set `solver.parameters.max_time_in_seconds = max_seconds`, `solver.parameters.num_search_workers = num_workers`. Extract `PackingResult`, then explicitly `del model, solver` before returning so C++ memory is freed immediately.
  </action>
  <verify>backend\.venv\Scripts\python.exe -c "from app.solver.cpsat_solver import solve_cluster_packing; print('imported')"</verify>
  <acceptance_criteria>
    - `cpsat_solver.py` contains NO float arithmetic inside `model.Minimize(...)` or `model.Add(...)`
    - `max_time_in_seconds` and `num_search_workers` are explicitly configured
    - Anti-affinity uses grouped `sum(...) <= 1`, not $O(N^2)$ pairwise constraints
  </acceptance_criteria>
